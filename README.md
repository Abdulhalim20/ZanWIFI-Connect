# ZanWIFI Connect 📶

A modern WiFi hotspot and business management platform designed for Zanzibar and Tanzania. It enables business owners to manage captive portals, handle mobile money billing, and integrate seamlessly with MikroTik routers.

## 🚀 Features
- **Captive Portal:** Beautiful landing and login pages for hotspot users.
- **Billing Integration:** Support for mobile money and local payment systems.
- **MikroTik Ready:** Easily control bandwidth, sessions, and user vouchers.
- **Responsive Dashboard:** Monitor revenue, active users, and hotspot status in real time.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Design System), JavaScript
- **Backend:** Node.js, Express
- **Hosting:** Render

## 📁 Project Structure
- `index.html` - Landing page / Home
- `login.html` - User / Admin login page
- `register.html` - Account registration page
- `server.js` - Backend server logic
- `package.json` - Project dependencies
